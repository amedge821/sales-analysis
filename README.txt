## 📊 Sales Analysis Project

### Overview

This project performs an exploratory data analysis (EDA) on a retail sales dataset to uncover key business insights,
including revenue trends,regional performance, and customer behavior. The analysis was conducted using Python, pandas,
and data visualization libraries.


### Objectives

* Analyze overall sales performance
* Identify top-performing regions and products
* Understand customer purchasing behavior
* Detect trends and patterns over time

---

### 🛠️ Tools & Technologies

* Python
* pandas
* matplotlib
* seaborn
* Jupyter Notebook

---

### 📂 Dataset

The dataset contains transactional sales data, including:

* Order Date
* Region
* Customer ID
* Product Category
* Sales
* Profit

---

### 🔍 Key Insights

* The **West region** generated the highest overall revenue, indicating strong market performance.
* A small group of customers contributed a significant portion of total sales.
* Sales showed noticeable **monthly trends**, with peak performance in certain periods.
* Some product categories consistently underperformed, suggesting potential optimization opportunities.
