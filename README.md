# Sales Data Analysis

## Overview
An exploratory data analysis project using Python to investigate sales performance across product categories, regions, customers, and time.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- **Regional Sales:** Compared total sales across regions.
- **Customer Analysis:** Identified the top 10 customers by total sales revenue.
- **Product Category Analysis:** Compared total sales across Technology, Furniture, and Office Supplies.
- **Monthly Sales Trends:** Examined monthly sales fluctuations and identified the highest- and lowest-sales months.
- **Data Cleaning:** Investigated duplicate records and missing values.

## Key Findings
- **Top Region:** West, with approximately $710,219.68 in sales.
- **Top Product Category:** Technology, with approximately $827,455.87 in sales.
- **Lowest-Selling Product Category:** Office Supplies, with approximately $705,422.33 in sales.
- **Highest-Sales Month:** November 2018, with approximately $87,997.64 in sales.
- **Lowest-Sales Month:** February 2015, with approximately $12,588.48 in sales.

## Project Structure
- `sales_analysis.ipynb` — Jupyter Notebook containing the analysis and visualizations.

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook or JupyterLab.
4. Run the cells from top to bottom.

## Limitations
This project explores historical sales patterns. Sales revenue does not measure profitability, and the analysis does not establish the causes of observed trends.
